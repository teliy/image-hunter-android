# Image Hunter — Android

Мобильный аналог [Image Hunter для Windows/Linux](https://github.com/teliy/image-hunter):
поиск картинок в вебе, оранжевые чекбоксы на плитках выдачи и массовое скачивание
отмеченных картинок в галерею телефона.

Ядро то же, что на десктопе: встроенный браузер (WebView) открывает выдачу
поисковика, а в неё внедряется **дословно тот же JavaScript** с чекбоксами
(`app/core/extractor.py` десктопной версии) — с эвристиками плиток Яндекса,
DuckDuckGo, Google, Bing, Brave и Sogou, раскрытием прокси-миниатюр
и подъёмом к обёртке, которая знает адрес оригинала.

## Возможности (v0.3.0)

- **Поиск** — 11 поисковиков, те же адреса выдачи, что на десктопе:
  Яндекс, DuckDuckGo (safe), Google, Bing, Brave, Startpage, Mojeek,
  Baidu, Sogou, Naver, Mail.ru;
- **Чекбоксы на плитках** — отмечайте нужные картинки прямо на выдаче,
  счётчик отмеченных обновляется на кнопке;
- **Скачать отмеченные** — для каждой плитки берётся большой оригинал
  (`best`, затем запасные `alts`), скачивание в `Pictures/ImageHunter`
  с `Referer` страницы выдачи, проверкой картинки и параллелизмом 3;
- **Собрать ссылки** — скачать все найденные на странице картинки
  (лучшие кандидаты — первыми) с подтверждением;
- **Десктопная версия страниц** — переключатель User-Agent в настройках:
  у части поисковиков мобильная выдача не даёт поставить чекбоксы;
- **Загрузки** — сетка скачанных картинок, предпросмотр, «Поделиться»,
  удаление (права на хранение не нужны — MediaStore);
- **Журнал** — те же события, что на десктопе: сколько плиток распознано,
  что скачалось и что нет;
- **Языки** — русский, английский, китайский (настройки → Язык);
- **Обновление из приложения** — настройка → «Проверить обновления»
  (и автопроверка раз в сутки): APK скачивается из GitHub Releases
  и ставится через системный установщик, как на десктопе;
- **WebDAV** — выгрузка сохранённых картинок на свой сервер:
  «Загрузить всё в WebDAV» на вкладке «Загрузки» (повторно — только новые,
  уже выгруженные пропускаются), одиночная выгрузка в превью и
  авто-выгрузка новых скачиваний (настройки → WebDAV: адрес, логин/пароль,
  папка, проверка соединения). Уроки десктопа учтены: запросы из фоновых
  потоков с таймаутами, последовательная загрузка — интерфейс не зависает;
- системная кнопка «Назад» работает как «назад в браузере».

## Установка

### Готовый APK

1. Откройте [Actions](https://github.com/teliy/image-hunter-android/actions)
   → последний успешный запуск **build** → артефакт `ImageHunter-…-debug-apk`;
2. Скачайте, разрешите установку из неизвестных источников, установите;
3. Либо откройте страницу [Releases](https://github.com/teliy/image-hunter-android/releases) —
   к каждому тегу прикладывается APK.

Требования: Android 10 (API 29) или новее. Приложение запрашивает только
разрешение на интернет (и, для обновления из приложения, право установки
«неизвестных приложений» — Android спросит при первой установке обновления).

### Обновление до новой версии

Начиная с v0.2.0 обновляться можно прямо из приложения:
**Настройки → Проверить обновления**. Приложение сверится с
[Releases](https://github.com/teliy/image-hunter-android/releases), скачает APK
и запустит установку; при первом обновлении Android попросит разрешить
Image Hunter «установку неизвестных приложений». Все APK проекта подписаны
одним ключом, поэтому новая версия ставится поверх старой без удаления.
Автопроверка выполняется не чаще раза в сутки и только сообщает о новой версии.

### Сборка из исходников

```bash
git clone https://github.com/teliy/image-hunter-android
cd image-hunter-android
./gradlew assembleDebug        # APK: app/build/outputs/apk/debug/
```

Нужны JDK 17 и Android SDK (в Android Studio достаточно открыть проект).

## Отличия от десктопной версии

| Десктоп (Windows/Linux) | Android v0.1.0 |
| --- | --- |
| 11 поисковиков, вкладки «как в браузере» | те же 11 поисковиков, один WebView, вкладки — в планах |
| «Найти везде» — запрос во все поисковики сразу | в планах |
| «Сохранить в формат» (WebP/PNG/JPEG/…) | в планах |
| «Мои картинки»: дерево дисков, папки, WebDAV-диск | сетка загрузок `Pictures/ImageHunter` + выгрузка на WebDAV |
| Удаление/переименование папок | предпросмотр, «Поделиться», удаление |
| Чекбоксы во вложенных фреймах (Mail.ru) | фреймы Android WebView недоступны: выдача Mail.ru — без чекбоксов |
| Журнал applog с таймингами | журнал событий (упрощённый) |
| Обновление из приложения | то же: Настройки → «Проверить обновления», APK из GitHub Releases |

## Если чекбоксы не появились

1. Откройте **Настройки → Десктопная версия страниц** — часть поисковиков
   отдаёт мобильную выдачу с другим DOM;
2. Загляните в **Журнал**: строка «плиток с чекбоксами: N» означает, что
   инъекция дошла до выдачи; «плиток не распознано» — поисковик снова сменил
   разметку (как на десктопе: пришлите журнал в issue);
3. Выдача картинок — обязательна: чекбоксы ставятся только на страницах
   картинок (`udm=2` у Google, `iax=images` у DDG и т.д.).

## Приватность

Приложение не имеет аналитики и серверной части: запросы уходят только
поисковикам, сайтам-источникам картинок и вашему WebDAV-серверу.
Настройки WebDAV (включая пароль) хранятся только локально.
Журнал хранится локально в памяти приложения.
